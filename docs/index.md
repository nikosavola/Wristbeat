# Wristbeat

Wristbeat turns a Wear OS watch into a standard Bluetooth heart rate sensor. Gym equipment, bike
computers, rowing machines and phone apps that ask for a heart rate belt find the watch instead, and
read the pulse it is already showing.

It is one button. There is no account, no history, no companion app and no network access at all. The
only thing that leaves the watch is the heart rate, sent over Bluetooth to the devices it is paired
with.

## Get it

Not published yet. It is being prepared for Google Play and F-Droid, and this page will say when it
is out. The source is at <https://github.com/nikosavola/Wristbeat>, where the README covers building
and installing it yourself.
